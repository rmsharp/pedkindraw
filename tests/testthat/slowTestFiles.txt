## Test files a CRAN check leaves out (tests/testthat.R, helper-slowTestFiles.R).
## CRAN rejects a package whose whole check takes more than 10 minutes on its
## Windows check machine, and win-builder R-devel read 980 s for this tree, 788 s
## of it the tests (S92; plan R165, target 540 s). This names every test file
## except those a CRAN check needs so that a test it runs calls each export: a
## run-time trace of every export over the CRAN-mode tests of the installed
## package chose them, slowest file first, a file named only while every export
## is still called by a file not named (an export counts for a file when the
## trace saw it called there and the file's own code calls it).
## test_slowTestFilesExports.R checks that by reading the code. CI and local runs
## set NOT_CRAN to "true" and still run every file. A test file added later runs
## on CRAN until it is named here. One name a line; `#` starts a comment.
